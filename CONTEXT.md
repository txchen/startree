# Personal Start Page

The Personal Start Page is a private website for navigating the owner's saved destinations and future personal tools.

## Language

**Owner**:
The sole person authorized to access and manage the Personal Start Page.
_Avoid_: User, account, administrator

**Page**:
A top-level area selected from the primary navigation.
_Avoid_: Section, tab

**Widget**:
A self-contained capability placed within a Page.
_Avoid_: Section, module

**Bookmarks Page**:
The Page that organizes and exposes the owner's saved destinations.

**Folder**:
A hierarchical container with a nonblank name that can hold Bookmarks and child Folders. Its name, exactly as entered, is unique among its siblings, and the tree is limited to ten Folder levels beneath the system root.
_Avoid_: Collection, bookmark group

**Bookmark**:
A named saved destination identified by an absolute HTTP or HTTPS URL, enriched with the owner's Tags and Note, and presented within a Folder. Its title is nonblank, and multiple Bookmarks may refer to the same URL.
_Avoid_: Link, favorite

**Tag**:
An owner-defined text label applied to a Bookmark for classification across the Folder tree.
_Avoid_: Label, category

**Note**:
An owner-authored plain-text annotation attached to a Bookmark.
_Avoid_: Description, comment

**Trash**:
The system-managed holding area for deleted Bookmarks and Folder trees.
_Avoid_: Folder, recycle folder
